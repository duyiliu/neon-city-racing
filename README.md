# Neon City Racing

一款受经典都市赛车 MMO 氛围启发的原创 3D 浏览器赛车原型。当前版本聚焦驾驶手感：在程序化霓虹城市中完成限时检查点任务，支持漂移与氮气加速。

## 启动

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址即可游玩。

## 操作

- `W / S` 或方向键上下：加速 / 倒车
- `A / D` 或方向键左右：转向
- `Space`：手刹漂移
- `Shift`：氮气
- `Esc`：暂停 / 继续
- `R`：重置任务

## 技术

- TypeScript + Vite
- Three.js WebGL 渲染
- 纯数据车辆与任务模拟，渲染层只负责画面同步
- DOM HUD，兼容桌面与窄屏

本项目使用原创名称、程序化几何和原创界面，不包含《光线飞车 / RayCity》的地图、标识、车辆、UI 或其他受版权保护素材。
